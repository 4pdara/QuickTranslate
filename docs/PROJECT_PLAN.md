# תוכנית פרויקט — QuickTranslate Desktop

ראו גם [../CLAUDE.md](../CLAUDE.md) לעקרונות המוצר וכללי העבודה.

## חזון

אפליקציית שולחן עבודה קלה שמאפשרת למשתמש לסמן טקסט בכל מקום במחשב, ללחוץ
קיצור מקשים, ולקבל תרגום מהיר בחלון פופאפ קטן — בלי לפתוח דפדפן, בלי הרשמה,
בלי שירותי ענן מיותרים.

## סדר מימוש (Implementation Order)

1. Bootstrap: Tauri v2 + React + TypeScript + Vite — **בוצע**
2. CLAUDE.md — זיכרון פרויקט — **בוצע**
3. קבצי תיעוד תחת `docs/` — **בוצע**
4. מעטפת אפליקציה RTL בעברית
5. מודל הגדרות ושמירה מקומית
6. הפשטת ספק תרגום (provider abstraction)
7. מימוש ספק DeepL
8. מימוש ספק Google Cloud Translation (אם פשוט)
9. חלון פופאפ תרגום צף
10. קיצור מקשים גלובלי
11. זרימת קליפבורד לטקסט מסומן
12. System tray
13. טיפול בשגיאות בעברית
14. עדכון תיעוד ו-CLAUDE.md
15. typecheck / build

## קריטריוני קבלה (Validation) ל-MVP

- האפליקציה נבנית בהצלחה (`npm run tauri build`).
- אין שגיאות TypeScript.
- CLAUDE.md קיים ומדויק.
- אין מפתחות API בלוגים.
- חוסר מפתח API מציג שגיאה ברורה בעברית.
- טקסט מסומן ריק מציג שגיאה ברורה בעברית.
- שגיאות תרגום מוצגות בצורה ידידותית למשתמש.
- ה-UI כולו RTL.
- קיצור המקשים מפעיל תרגום על טקסט מסומן בהצלחה.
- מסך הפתיחה הוא מסך התרגום, לא מסך ההגדרות.
- ברירת המחדל היא ספק חינמי/קוד פתוח, לא ספק בתשלום.
- ה-release build (`npm run tauri build`) לא פותח חלון CMD/קונסולה.
