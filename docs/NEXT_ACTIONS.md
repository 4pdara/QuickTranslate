# צעדים הבאים — QuickTranslate Desktop

מסמך זה מתעדכן בסוף כל milestone עם המצב הנוכחי והצעד המומלץ הבא.

## מצב נוכחי (עדכון אחרון — 2026-07-02, milestone M11)

שני סיבובי תיקון קודמים לקיצור המקשים (השוואת לוח, שחרור Shift/Alt) עדיין
היו מבוססי-לוח במהותם ולכן עדיין יכלו לפספס. בסיבוב הזה נבנה מנגנון חדש
לחלוטין: **SelectedTextCaptureEngine**.

- **שיטה ראשית — Windows UI Automation, בלי לוח כלל:**
  `src-tauri/src/capture/windows_ui_automation.rs` קוראת ישירות את הטקסט
  המסומן מהאלמנט הממוקד במערכת (`IUIAutomation::GetFocusedElement` +
  `TextPattern::GetSelection`), בלי לשלוח Ctrl+C ובלי לגעת בלוח בכלל. זו
  ברירת המחדל (`captureSelectedTextWithoutClipboard=true`).
- **שיטה משנית — fallback ללוח, כבוי כברירת מחדל:** אם UI Automation נכשל
  (אפליקציה לא תומכת), ורק אם `allowClipboardFallbackForSelectedText=true`
  (המשתמש חייב להפעיל את זה במפורש), עוברים לשיטת ה-Ctrl+C+פולינג מהסיבובים
  הקודמים — ללא שינוי בלוגיקה שלה.
- אם UI Automation נכשל וה-fallback כבוי: שגיאה ספציפית "לא הצלחתי לקרוא
  את הטקסט המסומן באפליקציה הזו. אפשר להפעיל fallback ללוח בהגדרות." (לא
  השגיאה הגנרית הישנה).
- מבנה קוד חדש: `src-tauri/src/capture/{mod,selected_text,windows_ui_automation,clipboard_fallback}.rs`.
- תלות חדשה: `windows` crate (Win32 UI Automation + COM), Windows בלבד
  (`#[cfg(windows)]` — לא שובר build על פלטפורמות אחרות בעתיד).
- הגדרות הגדרות חדשות בסקשן "לכידת טקסט מסומן" ב-`SettingsView`.
- אומת: `tsc --noEmit`, `npm run build`, `cargo check` ו-`cargo check --release`
  (שניהם **ללא אזהרות**), `npm run tauri build` (release + installer) — כולם עוברים.

## מגבלה מתועדת (לא הבטחה אוניברסלית)

UI Automation עובד רק באפליקציות שמיישמות `TextPattern`/`ITextProvider`:
Notepad, רוב תיבות הטקסט הסטנדרטיות של Windows, WPF, ורוב הדפדפנים
המודרניים (Chrome/Edge/Firefox) על אזורי טקסט. **לא בטוח שיעבוד** באפליקציות
עם רינדור מותאם (canvas, חלק מ-Electron/Qt/משחקים). במקרים האלה, אם המשתמש
לא הפעיל את ה-fallback ללוח, תוצג שגיאה ברורה (לא תרגום שגוי שקט).

## מה לא נבדק עדיין (דורש בדיקה ידנית של המשתמש — לא ניתן לאמת מסוכן)

- **קריטי:** Notepad, דפדפן, ועוד אפליקציות — לבדוק שה-UI Automation תופס
  טקסט מסומן בלי לגעת בלוח (להשוות תוכן לוח לפני/אחרי).
- אפליקציות שבהן UI Automation **לא** עובד (למשל אפליקציות עם canvas מותאם)
  — לבדוק שמופיעה השגיאה הנכונה, ושה-fallback ללוח (אם מופעל) עוזר שם.
- שני המצבים של `allowClipboardFallbackForSelectedText` (דלוק/כבוי).

## הוראות בדיקה ידנית (מדויקות)

**1. Notepad, בלי fallback ללוח (ברירת מחדל):**
1. וודא ש"אם לא הצליח — השתמש בלוח ההעתקה" כבוי בהגדרות.
2. פתח Notepad, הקלד טקסט, סמן חלק ממנו.
3. שים תוכן **אחר** בלוח (Ctrl+C על משהו לא קשור) לפני זה.
4. לחץ Ctrl+Shift+T.
5. **צפוי:** מתורגם הטקסט שסימנת ב-Notepad (לא תוכן הלוח), והלוח עדיין מכיל
   את התוכן הלא-קשור (לא השתנה).

**2. דפדפן, בלי fallback ללוח:**
1. סמן טקסט בעמוד אינטרנט (לא input/textarea — טקסט רגיל בעמוד).
2. לחץ Ctrl+Shift+T.
3. **צפוי:** מתורגם הטקסט שסומן. (אם הדפדפן/האזור הספציפי לא תומך
   ב-Accessibility כראוי, ייתכן כשל — זו המגבלה המתועדת; דווח איזה אתר/דפדפן.)

**3. בלי טקסט מסומן, fallback ללוח כבוי:**
1. לחץ במקום ריק (בלי לסמן שום טקסט).
2. לחץ Ctrl+Shift+T.
3. **צפוי:** "לא הצלחתי לקרוא את הטקסט המסומן באפליקציה הזו. אפשר להפעיל
   fallback ללוח בהגדרות."

**4. בלי טקסט מסומן, fallback ללוח מופעל:**
1. הפעל "אם לא הצליח — השתמש בלוח ההעתקה" בהגדרות.
2. שים טקסט בלוח (Ctrl+C).
3. לחץ במקום ריק בלי לסמן טקסט, ואז Ctrl+Shift+T.
4. **צפוי:** מתורגם תוכן הלוח, עם ההערה "הטקסט תורגם מהלוח כי הלוח לא השתנה."

**5. בדיקת שלמות הלוח:**
1. לפני בדיקה 1 או 2, פתח את היסטוריית הלוח של Windows (Win+V) ורשום מה יש בה.
2. אחרי הרצת הקיצור, פתח שוב את Win+V ווודא שההיסטוריה לא נמחקה/השתנתה
   באופן בלתי-צפוי (כשה-UI Automation מצליח, הלוח לא אמור להיגע בכלל).

**אתר נחיתה:** `site/` — Vite + React + TS + Hebrew RTL. 9 סקשנים.
GitHub Pages workflow: `.github/workflows/deploy-pages.yml`.

**GitHub Release v0.1.0:** NSIS setup.exe + MSI + portable ZIP.

## שינויים במילסטון M11 (2026-07-02)

- **תפריט מגש משופר:** נוסף "פתח מתרגם" בראש התפריט (פותח חלון ראשי ומסך
  תרגום, ללא ניווט להגדרות). סדר: פתח מתרגם → פתח הגדרות → תרגם טקסט מהלוח
  → יציאה.
- **חלון קומפקטי:** ברירת המחדל הוקטנה ל-720×520 (הייתה 760×620). minHeight
  הוקטנה ל-440. ה-CSS הוכווץ (panel min-height: 160px, padding מוקטן, gaps
  מוקטנים). אין min-height: 100vh — הגובה נקבע לפי התוכן.
- **web preview mode:** זיהוי Tauri (`isTauri()`), localStorage fallback
  להגדרות, באנר "מצב תצוגת אתר" בדפדפן, כפתור מזעור מוסתר בדפדפן.
  לוגיקת לכידה/תרגום/ספקים: לא שונתה.

## הצעד המומלץ הבא

1. בדיקה ידנית של 5 התרחישים מ-M10, בדגש על Notepad ודפדפן.
2. לאסוף רשימת אפליקציות שבהן UI Automation לא עובד.
3. לעבור למילסטון הבא: קיצור מקשים דינמי בלי הפעלה מחדש, ו/או פופאפ סמוך
   לעכבר.

## פתוחות / לאישור משתמש

- ברירת המחדל הנוכחית היא `libretranslate` (דורש הזנת כתובת שרת בהגדרות) —
  לאשר שזה הכיוון הרצוי, או לשנות ברירת מחדל לספק שעובד מהקופסה.
- שם תצוגה סופי לאפליקציה (כרגע `QuickTranslate` / identifier
  `com.quicktranslate.desktop`).
