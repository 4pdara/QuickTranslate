# Windows QA — QuickTranslate 0.1.1

תאריך: 2026-09-16. ענף עבודה: `codex/windows-stability`.

## ממצאים ותיקונים

העותק המקורי כבר פעל במגש. הפעלת עותק נוסף גרמה ל-panic בגלל קיצור תפוס
(`HotKey already registered`). אין להסיק מכך שהעותק המקורי לא פעל.
הוספו single-instance, פתיחת חלון קיים וטיפול בהתנגשות בלי קריסה.

בבדיקת תרגום ללא API הופיעו HTTP 429 מ-Google ו-403 מ-Lingva. בדיקה מאוחרת
החזירה תרגום תקין מכתובות Google (`Good morning` → `בוקר טוב`). ספק Google
עודכן לניסיון מוגבל דרך שתי כתובות שלו ולאימות מבנה התשובה.

## בדיקות שבוצעו

- 16 בדיקות Vitest עברו: ביטול תוצאות מאוחרות, שימור טקסט במעבר להגדרות,
  העתקה שנכשלה, הודעת התנגשות קיצור, אימות ספקים, timeout כולל גוף תשובה,
  מעבר בין כתובות Google ותשובות לא תקינות.
- בדיקת Rust לאימות קיצורי מקשים עברה.
- TypeScript ו-Vite build עברו.
- `npm audit`: אפס ממצאים לאחר עדכונים תואמים לתלויות פיתוח.
- בניית NSIS ו-MSI של 0.1.1 עברה לפני עדכון כתובות Google; בנייה סופית בבדיקה.
- הפעלה נוספת לאחר מזעור למגש החזירה אותו חלון; נשאר תהליך יחיד (נבדק בפועל).
- ההגדרות הקיימות נטענו, כולל `Ctrl+Shift+Q` וספק Google ללא API.

## עדיין בבדיקה

- תרגום עברית/אנגלית מתוך הבינארי הסופי לאחר עדכון כתובות Google.
- קיצור מקשים מול מסמך בדיקה ייעודי, והבדל מול מצב שאין בו טקסט מסומן.
- שינוי קיצור חי ופתיחה בלחיצה על אייקון המגש.
- בדיקת התקנה על מחשב Windows נקי לא בוצעה.

## פרטיות ופרסום

לא נוסף מפתח API. בהגדרות המקומיות כבר היה מפתח Google Cloud; הספק נבחר
זמנית לבדיקת חיבור ואז הוחזר ל-Google ללא API לבקשת המשתמש. לא נשמר מפתח
בקוד/בלוגים/בריפו. בדיקות בתשלום הופסקו.

לא פורסמה גרסה חדשה ולא נדחפו שינויים ל-GitHub בשלב זה. פרסום מותנה באימות
התרגום וההתנהגות של גרסת Windows הסופית.
