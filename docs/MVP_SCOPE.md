# תחום ה-MVP — QuickTranslate Desktop

מסמך זה הוא רשימת בדיקה (checklist) לתחום ה-MVP. כל שינוי בתחום צריך להתעדכן
גם כאן וגם ב-[../CLAUDE.md](../CLAUDE.md).

## בתוך תחום ה-MVP

- [x] Tauri v2 desktop app (Windows)
- [x] React + TypeScript frontend
- [x] UI בעברית, RTL מלא, עיצוב מודרני (כרטיסים/צללים, לא טופס שטוח)
- [x] **מסך תרגום ראשי נפתח כברירת מחדל** — לא מסך הגדרות
- [x] מסך הגדרות נפרד, נפתח רק בלחיצה מפורשת (כפתור/תפריט מגש/פופאפ)
- [x] באנר "ספק חסר" במסך התרגום עם כפתור "פתח הגדרות", במקום לחסום את המסך
- [x] System tray (אייקון + תפריט)
- [x] קיצור מקשים גלובלי (default `Ctrl+Shift+T`)
- [x] תרגום טקסט מסומן דרך זרימת קליפבורד (קיצור מקשים → פופאפ), **עם השוואת
      לוח ישן/חדש** כדי לא לתרגם בטעות תוכן ישן — וכדי לא למחוק/לאפס את הלוח
- [x] הגדרה אופציונלית `allowUnchangedClipboardFallback` ("תרגם גם אם הלוח לא השתנה")
- [x] תרגום ידני בתוך המסך הראשי (הקלדה/הדבקה → תרגם → תוצאה בפאנל יעד)
- [x] בחירת שפת מקור/יעד + כפתור החלפת שפות במסך הראשי
- [x] זיהוי כיוון עברית/אנגלית אוטומטי (`autoDetectDirection`)
- [x] חלון פופאפ תרגום צף
- [x] הפשטת ספק תרגום (`TranslationProvider`) עם קטגוריות חינמי/ניסיוני/מתקדם
- [x] **כיוון ברירת מחדל: ספקים חינמיים/קוד פתוח**, לא ספק בתשלום
- [x] ספק Google Translate — ללא API (ניסיוני, ללא מפתח)
- [x] ספק LibreTranslate (חינמי/קוד פתוח, כתובת שרת מותאמת)
- [x] ספק Lingva Translate (ניסיוני, חינמי)
- [x] ספק Google Cloud Translation (מתקדם, דורש מפתח בתשלום) — נשמר כאופציה יציבה
- [x] ספק DeepL (מתקדם, דורש מפתח) — נשמר
- [x] ספק Azure Translator — stub/interface בלבד
- [x] אחסון מפתחות API וכתובות שרת מקומי בלבד
- [x] מצבי שגיאה ברורים בעברית בכל המסכים
- [x] release build לא פותח חלון CMD/קונסולה (`windows_subsystem = "windows"`)
- [x] CLAUDE.md
- [x] קבצי תיעוד (`docs/`)

## מפורשות מחוץ לתחום (Out of Scope) — לא לממש בלי אישור מפורש

- OCR (תרגום מתוך תמונות/צילומי מסך)
- חשבונות משתמש / authentication
- Backend בענן
- Billing / תשלומים
- היסטוריית תרגום כבדה (היסטוריה קטנה ומקומית בלבד תיתכן בעתיד)
- סנכרון בין מכשירים
- תוסף דפדפן
- אפליקציית מובייל
- מעבר ל-Electron
- **אוטומציית דפדפן** (Selenium/Puppeteer/Playwright) או פתיחת חלון דפדפן
  חבוי לשום ספק תרגום
- **סקרייפינג עמודי HTML מלאים** של Google Translate או כל ספק אחר

**הבהרה:** ספק "Google Translate — ללא API" **אינו** scraping של עמוד HTML
ואינו אוטומציית דפדפן — הוא קורא ל-endpoint ציבורי מבוסס JSON (`translate_a/single`)
ששירות אתר Google Translate עצמו משתמש בו. זה עדיין לא-רשמי (אין הסכם רמת
שירות, עלול להיחסם/להשתנות), ולכן הוא מסומן "ניסיוני" ולא הוא ברירת המחדל
היחידה — אך הוא קל-משקל ועקבי עם שאר הספקים (קריאת HTTP ישירה, לא דפדפן).
